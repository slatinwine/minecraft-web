# 我的世界 · Web Edition

单文件网页版 Minecraft（Three.js 体素渲染）。

## 玩法

- 在线游玩：<https://slatinwine.github.io/minecraft-web/>
- 本地：直接用浏览器打开 `index.html`

## 操作

| 按键 | 功能 |
| --- | --- |
| W A S D | 移动 |
| 空格 | 跳跃 |
| 鼠标左键 / 右键 | 挖掘 / 放置方块 |
| 1~9 / 滚轮 | 切换方块 |
| Shift | 疾跑 |
| F | 飞行（空格升 / Shift 降） |
| ESC | 暂停 |

每次刷新随机生成新世界。建议使用桌面版 Chrome / Edge。
